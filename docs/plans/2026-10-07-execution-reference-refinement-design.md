# 执行参考补充范围（用户已确认）

日期：2026-10-07。

## 目标与取舍

在现有 UEDJudge 主控参考中补充可选择的方法，帮助模型把视觉、动效与响应式问题落实为具体改动。借鉴 finesse-ui 的推导与排查思路，不整包引入规则，也不把其风格偏好变成评分标准。

用户明确选择四项：

1. 视觉参考补充配色推导与表面层级示例。
2. 动效参考补充展开收起、筛选更新、短操作反馈、异步操作四类案例。
3. Web 质量参考补充响应式根因排查路径。
4. SKILL 索引按问题加载，不要求每次读完所有执行参考。

用户明确排除组件级实现范例；不创建组件示例文件、固定组件外观、状态预览页或组件库依赖。

## 文件与边界

- 维护源：普通版已有 visual-optimization、motion-optimization、web-interface-quality 三份参考；SKILL 只承载加载条件。
- Pro 共用文档由 sync-pro-core 生成，入口增加同等加载提示；报告模板与生成器不变。
- 不改变冻结正文、硬检查阈值、执行约束、报告流程、评委输入或调用预算；新增内容不单独计分。
- 保留原技术栈、原有功能、业务数据与文案意图；不默认新增主题切换、取消/重试等能力。
- 本轮记录为 Unreleased；不发布版本、不安装全局副本、不修改 TC1、不提交或推送。

## 验证范围

本轮验证 skill 结构、索引链接、共用副本一致性、Pro 现有测试及冻结文件未变，并人工检查新增方法与原规则的适用边界。

真实优化收益需在用户发起的新测试中验证：从原始 TC1 出发，固定模型、主题、任务范围和截图参数，沿用盲评成对比较；动效另以实际操作核验。静态规则检查不当作视觉或模型行为提升的证据。
