# docs —— 方案 / 蓝图 / 设计决策记录

本目录存放 UEDJudge 的**过程性文档**：实施方案、蓝图、设计决策记录（ADR）、调研笔记等。

与其它文档的分工：
- 面向使用者的说明 → 根目录 `README.md`。
- 评估规范的事实源 → `skills/ued-judge/references/`。
- 跨会话上下文台账 → 根目录 `PROJECT_CONTEXT.md`。
- 本目录 → 规划、论证、决策过程的留存，不作为规范事实源。

## 命名约定
建议按 `YYYY-MM-DD-<主题>.md` 命名，便于按时间检索。例如：`2026-09-29-evaluation-framework-plan.md`。

> 当前为空目录占位。产出方案/蓝图时在此新增文档，并在 `PROJECT_CONTEXT.md` 文件地图与变更日志中登记。
