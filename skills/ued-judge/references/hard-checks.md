# 硬性检查清单（hard-checks）

评论员做的是审美与整体体验的主观盲评，容易漏掉可量化的合规项。本清单由**主控**独立执行，结果与评论员结论并列写进报告，**不影响评论员评分**。

## 判定规则

- 每项给出：`通过` / `不通过` / `无法判定`，并附证据（元素、实测数值、代码位置）。
- 只判断输入能支撑的项：仅有截图时，依赖 DOM/代码的项一律标 `无法判定`，不猜。
- 严重度：`阻断`（必须进阶段一）/ `一般`（按收益归入阶段）。

## 清单

| # | 检查项 | 标准 | 严重度 | 判定依据 |
|---|---|---|---|---|
| H1 | 正文文字对比度 | ≥ 4.5:1（WCAG AA） | 阻断 | 截图取色或计算 CSS 色值 |
| H2 | 大字 / 图标 / 控件边界对比度 | 大字（≥18.66px 粗体或 ≥24px）≥ 3:1；非文字 UI 元素 ≥ 3:1 | 一般 | 同上 |
| H3 | 仅靠颜色传达信息 | 状态、优先级、数据系列除颜色外还有文字 / 图标 / 形状 | 阻断 | 截图 + DOM |
| H4 | 焦点可见 | 所有可交互元素有可见的 `:focus-visible` 样式，未被 `outline: none` 裸去除 | 阻断 | 代码 |
| H5 | 键盘可达 | 关键路径上的操作可用 Tab / Enter / Space 完成，无键盘陷阱 | 阻断 | 代码 / 实测 |
| H6 | 可访问名 | 纯图标按钮有 `aria-label`；表单控件有关联 `<label>` | 一般 | 代码 |
| H7 | 最小字号 | 正文 ≥ 14px；辅助信息 ≥ 12px | 一般 | 截图 + 代码 |
| H8 | 点击目标尺寸 | 可点击区域 ≥ 24×24px（触屏场景 ≥ 44×44px） | 一般 | 代码 / 截图 |
| H9 | 状态覆盖 | 关键区域有加载、空、错误状态，不是空白或裸报错 | 一般 | 代码 / 实测 |
| H10 | 响应式 | 在 1440 / 1024 / 768 / 375 宽度下无横向溢出、无内容遮挡 | 一般 | 多视口截图 |
| H11 | 减弱动效 | 有动画时尊重 `prefers-reduced-motion` | 一般 | 代码 |
| H12 | 敏感信息展示 | 密钥、口令等默认遮蔽，不以明文显示在界面上 | 阻断 | 截图 + 代码 |

H10 需要额外截图，这些截图**只给主控用，不给评论员**。
