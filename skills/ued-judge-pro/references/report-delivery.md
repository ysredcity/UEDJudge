# Pro 报告交付协议

只升级呈现和报告资源写入，评审、优化、核验与共用 `critic-protocol.md` 相同。共用规范的「不写报告文件」及 Step 6「不修改任何文件」在 Pro 中仅对报告 JSON/HTML 及资源例外；被评估源码、配置、数据和其他非报告文件仍不得修改。规则冲突时仅在这个明确范围采用本协议。

## 一套结论，两种呈现

先按共用 `report-template.md` 组织完整诊断/收尾内容；结构化数据只是这些结论的投影，不另做评判。分数由原始样本记录展示，生成器确定性换算；原样保留评论员/核验员原文、格式不完整、依据越界、标签错位、评分不稳定、无法判定以及覆盖不足。别为了让图表好看补分、删条目或抬高置信度。

JSON 中 `fullReport` 保留完整报告，`rawReviews` 保留本报告相关的所有原始评语；截图、差距、检查、阶段和核验结构字段逐条与正文对照。没有精确坐标时只定位到截图，不编造框；未知分数用 null，有空缺的平均显示「无法汇总」而非零。差距 G1 与几何检查 G1 属于不同命名空间，引用必须写 type。

默认展示按共用模板的「默认摘要」组织：结论、关键问题、执行方案或改善结果、保真与授权边界在正文；评分表、已通过检查、完整说明和原始评语可展开。新报告各 `sections` 段填写人工整理的 `summary`，`body` 仍保留全部依据；旧报告缺少摘要时默认展开原文，不由生成器截断、猜测或重写。所有 P0/P1、阻断、退步、无效比较、未达成目标的原因、影响结论/执行的未知项和授权例外，必须在摘要或默认展开的结构化结果中逐条可见，不能只写「详见完整报告」。详情折叠不减少诊断、阶段动作/目标、自检、复评或核验工作。

## 诊断报告

固定内容：对象/版本/模型/使用途径/能力边界，原始截图，双样本评分与不稳定提示，差距置信度，硬性检查与 W/M 证据，视觉保护与功能/文案保真，数据提示和改善边界，1–3 阶段及目标状态。完整报告和原始样本可展开阅读，不用摘要代替。

筛选只改变浏览，不改变结论、阶段或执行范围。选择「只要报告 / 逐阶段 / 一次性」或阶段子集、填写备注后，可预览并复制反馈。生成反馈携带 run-id、内容指纹、对象和阶段；显示「选择未执行」。用户粘贴后主控核对对应运行与范围，再按共用协议继续。阶段备注若要求功能/语义变更，仍单独确认。

可执行时将「一次性执行以上 N 个阶段」排在首位并标为推荐（两阶段时可写「一次性执行以上两阶段」），说明逐阶段自检、最后统一复评与核验；N 使用本次实际阶段数，不固定为两阶段。仍保留逐阶段执行、只要报告和阶段子集。初次打开默认仍为「只要报告」，推荐不等于预选、授权或执行；恢复的本地草稿同样不授权。只有截图、无写入能力或无可执行阶段时不展示执行推荐。

诊断交付后结束回复。报告不提供多风格优化草图；浏览/选择本身不触发评委，用户选择执行后仍按共用协议完成必要复评，不增加报告专用的评委调用。

## 前后对照报告

使用初评与最终已有截图，不为报告修改页面或补评。总览/切片按明确标识配对；缺少一侧、状态不对应或采样范围不同的情况如实提示。放大只是查看，不能作为响应式/交互合规证据。

优先呈现务实目标结论、未通过/无法判定条件、差距核验摘要、成对比较摘要（退步/无效项展开）、改善与剩余问题、保真和验证限制。全部四个目标条件、六维成对证据、完整检查、阶段动作与参考评分明细可展开；所有核验状态原样显示，部分解决与无法判断不伪装已解决。用户看到的「优化前/后」标签不传给盲评评论员。

对照报告不提供一键应用、回退或自动开始新诊断。可复制备注供用户主动提出下一步，不自动追加轮次。

## 运行与资源

- 输出放工作目录 `./.ued-judge/reports/<run-id>/`；JSON 中 PNG 路径相对 JSON 所在目录或为绝对路径。不要在报告 JSON 放凭证、token、非必要敏感信息。截图可能包含业务数据，提示本地报告分享风险。
- 不依赖运行服务器、CDN、远程字体或框架；HTML 内嵌 PNG、CSS、JS。默认不加载原始页面 iframe，不联网、不提交表单；所有输入按文本呈现，不能作为代码执行。
- 选择/备注仅保存在当前浏览器本地，按内容指纹隔离，用户可清除草稿。存储不可用仍可选择、手工复制。复制权限失败显示可选择文本，不能声称已复制成功。
- 同一报告输出默认不覆盖，明确重新生成时使用 `--force`；覆盖前不要丢失仍需保留的历史报告。
- 未打开 HTML、禁用脚本、剪贴板/存储不可用、生成失败或运行能力不足时，提供真实的对话报告/摘要与文件，不要求安装新框架或降低平台安全保护。

## 主控交付自检（不消耗评委调用）

逐条核对 JSON 与完整报告的评分、原判定、G 编号、置信度、检查证据、保真清单和阶段；再核对默认摘要没有遗漏上述关键风险、未知项或授权边界。打开生成页确认摘要/展开详情、推荐不预选、图片、定位/筛选、移动布局和反馈可用。可利用导出 JSON 与完整文字检查，无 UI 能力时注明未验证，不把文件生成成功说成交互已验证。报告 UI 的缺陷修复不修改评审结论，也不算新增优化阶段。
